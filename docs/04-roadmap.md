# 04. 各Phaseの実装内容

各 Phase は「単体で動作確認できる」ことを完了条件にします。同時並行では実装しません。

---

## Phase 1 — アプリ基盤 ✅ 完了

**実装**
- Tauri 2 + React + TypeScript + Vite プロジェクト
- SQLite 接続・マイグレーション（全テーブル）
- 設定ファイル（`settings.json`）の読み書き
- ロギング（`tracing` → ファイル）
- エラー型 `AppError` と IPC でのエラー返却
- ホーム画面 / 過去会議一覧（空状態を含む）
- 新規会議作成 → `draft` レコード
- 会議詳細画面の骨組み
- 設定画面（保存先・モデル選択・トグル類）

**完了条件**: 会議を作成でき、一覧に出て、再起動しても残っている。

---

## Phase 2 — 録音（最重要） ✅ 完了

**実装**
- `audio/devices.rs` 入力デバイス列挙
- `audio/recorder.rs` cpal ストリーム、開始/一時停止/再開/停止
- `audio/resample.rs` デバイスレート → 16kHz mono
- `audio/wav_sink.rs` 逐次書き込み・5秒ごとの flush + ヘッダ更新
- `audio/recovery.rs` 起動時のクラッシュ復旧
- 会議中画面（会議名 / 録音中表示 / 経過時間 / 入力レベル / 一時停止 / 会議終了）
- 会議終了の確認ダイアログ
- ディスク空き容量チェック（開始前・録音中）
- マイク権限・デバイス無しのエラー表示

**この Phase 単体でテストすること**
1. 開始 → 5分 → 終了 → 再生できる
2. 一時停止 → 再開 → 一時停止区間が無音でなく「詰められている」
3. 録音中にアプリを強制終了 → 再起動 → 復旧ダイアログ → 音声が再生できる
4. 3時間の連続録音でメモリ使用量が増え続けない
5. 録音中にマイクを抜く → エラー表示され、それまでの音声は残る

**完了条件**: 上記5項目が全て通る。

---

## Phase 3 — 終了後の高精度文字起こし ✅ 完了

**実装**
- `stt/models.rs` モデル一覧・ダウンロード・SHA検証・保存先管理
- `stt/whisper.rs` whisper-rs による文字起こし（精度優先設定）
- 進捗イベント（%・処理済み秒数）
- `transcript_segment(kind='final')` / `transcript.raw.txt` 出力
- 設定画面でのモデル未導入検出とダウンロード導線
- 文字起こし失敗時に音声が残ることの確認

**完了条件**: 録音 → `transcript.txt` が生成される。

---

## Phase 4 — Ollama 連携 / AIまとめ

**実装**
- `llm/mod.rs` `LlmProvider` trait
- `llm/ollama.rs` 生成・モデル一覧・疎通確認
- `llm/schema.rs` 構造化出力の型と JSON Schema
- `llm/chunking.rs` 長文の階層処理
- `llm/summary.rs` まとめ生成 → `summary.md`
- Ollama 未起動 / モデル未導入の検出と案内
- AI失敗時も音声・文字起こしが残ることの確認

**完了条件**: 文字起こし → `summary.md` が生成される。

---

## Phase 5 — 議事録生成 ★ここで MVP 完成

**実装**
- チャンクごとの構造化抽出 → `meeting_note` / `action_item` へ即時永続化
- 構造化データの統合（コードによる重複排除）
- `llm/minutes.rs` → `minutes.md`
- 終了後画面（音声 [再生][保存] / 議事録 [内容を見る][保存] / AIまとめ [内容を見る][保存] / [保存フォルダを開く]）
- `metadata.json` 出力
- パイプラインのステップ再実行

**MVP 完成条件（仕様書 26 章）**
- [x] 新しい会議を作成できる
- [x] 任意で事前情報を入力できる（Phase 6 で完全対応。Phase 5 時点では会議名のみ）
- [x] スキップして即開始できる
- [x] 会議を録音できる
- [x] 録音音声が保存される
- [x] 会議終了後に文字起こしできる
- [x] AIが議事録を作成できる
- [x] AIがまとめを作成できる
- [x] 音声・議事録・まとめを確認・保存できる
- [x] 過去の会議をアプリから開ける

## Phase 8 — リアルタイムAI分析

**実装**

- `analysis_snapshot` 保存 / `analysis:update` イベント
- 会議中画面の分析ペイン（現在の議題 / 決定事項 / ネクストアクション / 注意事項 / 未決事項）
- 設定 ON/OFF、失敗時の再試行

**完了条件**: 会議中に分析が更新される。失敗しても録音・文字起こしが継続する。

## MVP で実装しないもの（仕様書 22 章）

クラウド同期 / ユーザー登録 / ログイン / 課金 / チーム共有 /
Slack・Google Meet・Zoom・Teams 連携 / 完全な自動話者識別 / 声紋登録 / 自動メール送信

**拡張余地の残し方**
- `LlmProvider` / `Transcriber` を trait 化し、実装差し替えのみで変更可能にする
- 会議データは自己完結したフォルダ単位。将来の同期・共有はフォルダ転送で実現できる
- `metadata.json` に構造化データを持たせ、外部連携時に再解析を不要にする
